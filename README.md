# 💳 C++ Bank Management System

> A feature-rich C++ banking management system built throughout my learning journey, demonstrating file handling, modular programming, authentication, role-based permissions, and console application design.

---

# 📖 Overview

This project is a **console-based Bank Management System** developed in **C++** as part of my early programming journey.

Rather than being built in a single sitting, the project evolved over an extended period through multiple development phases. Each phase introduced new programming concepts and features as I progressed in learning C++. The final result is a complete console application that combines client management, banking transactions, user authentication, role-based access control, and an ATM simulation.

The source code has been intentionally preserved in its original form to reflect my learning process and demonstrate how the project evolved over time.

---

# 🎯 Project Objectives

The primary goal of this project was to practice and strengthen my understanding of:

* Object-oriented thinking (using structures and modular functions)
* File handling and persistent data storage
* CRUD (Create, Read, Update, Delete) operations
* Console application development
* Authentication and authorization
* Modular program organization
* Working with vectors and STL
* Building a complete multi-module application

# 💾 Data Storage

The application uses simple text files as a lightweight database.

Current data files include:

* Bank_Data.txt
* Users.txt
* ClientData.txt

This approach was intentionally chosen for learning purposes to gain practical experience with file handling before working with relational databases.
